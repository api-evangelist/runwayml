# Runway Dev

> Runway Dev exposes generative video, image, and audio models over HTTP, plus real-time conversational Characters and saved model routing configurations. Most generation endpoints are asynchronous: send a request to receive a task id, then poll `GET /v1/tasks/{id}` until the task reaches `SUCCEEDED` or `FAILED`. Every request must include an `X-Runway-Version` header. Request bodies on generation endpoints are discriminated unions keyed on `model`, so the valid `ratio`, `duration`, and optional fields depend on which model is selected.

Every documentation page is also available as raw Markdown by appending `.md` to its path, for example `https://docs.dev.runwayml.com/guides/using-the-api.md`.

- Start with [/ai-context.md](https://docs.dev.runwayml.com/ai-context.md) if you only read one file. It covers authentication, the task lifecycle, and the complete capability surface in a few thousand tokens.
- [/api.md](https://docs.dev.runwayml.com/api.md) is a generated reference for every endpoint, including per-model request fields and their allowed values. Read it before constructing a request body.
- [/openapi.json](https://docs.dev.runwayml.com/openapi.json) is the machine-readable OpenAPI 3.1 specification.
- Credit costs are documented only in [/guides/pricing.md](https://docs.dev.runwayml.com/guides/pricing.md). Do not infer pricing from anywhere else.
- Model identifiers change over time. Only use identifiers listed in [/guides/models.md](https://docs.dev.runwayml.com/guides/models.md) or `/api.md`.
